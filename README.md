# Push-Ups

A home-screen web app for a six-week push-up plan (goal: 50 in a row). It reads today's date and shows that day's workout, lets you log each set, times your rest, and tracks max tests.

**Open it:** https://rossdavilla.github.io/push-ups/ — in Safari on iPhone, tap Share → Add to Home Screen.

## The plan (starts Monday, Nov 16, 2026)

| Day | Workout |
| --- | --- |
| Mon | Strength: 4 × 6–10 of a harder variation (weighted, feet-elevated) |
| Tue | Easy: 1 × 25 |
| Wed | Volume: 3 × 25+ |
| Thu | Easy: 1 × 25 |
| Fri | Endurance: 2 × 30+ |
| Sat | Easy (optional): 1 × 20–25 |
| Sun | Rest |

- Weeks 1–2 hold the targets. In weeks 3–5, Wednesday and Friday go up 1 rep per set each week, but only if you finished every set the previous time.
- Week 3: Thursday off, max test Friday.
- Week 6: taper (Mon 2 × 6–8, Tue/Wed 1 × 15, Thu off), final max test Friday.

The log is stored on the phone (localStorage). Progress → Backup copies it as text.
